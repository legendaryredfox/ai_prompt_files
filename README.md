# ai_prompt_files

## Português

Coleção de arquivos de instruções (prompts) para agentes de IA de programação, como o Claude Code. Cada pasta guarda o material de um projeto.

### Conteúdo

| Pasta | Descrição |
|---|---|
| `oscr_minimal/` | `CLAUDE.md` do dumper mínimo de cartuchos SNES / NES / Famicom / Mega Drive / GBA, derivado do Open Source Cartridge Reader (OSCR) |

### Uso

Copie o arquivo da pasta desejada para a raiz do projeto de destino (por exemplo, `CLAUDE.md`) para que o agente leia as instruções ao iniciar.

## English

Collection of instruction files (prompts) for AI coding agents such as Claude Code. Each folder holds the material for one project.

### Contents

| Folder | Description |
|---|---|
| `oscr_minimal/` | `CLAUDE.md` for the minimal SNES / NES / Famicom / Mega Drive / GBA cartridge dumper, derived from the Open Source Cartridge Reader (OSCR) |

### Usage

Copy the file from the desired folder to the root of the target project (for example, as `CLAUDE.md`) so the agent reads the instructions on startup.

### Author

Legendary Redfox
